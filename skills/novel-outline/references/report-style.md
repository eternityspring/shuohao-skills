# 大綱報告的設計約定

報告由 `scripts/novel-outline.mjs render --html` 生成，樣式全部內聯在 `renderHtml()` 裡。**改樣式只改那一處。**

## 它是什麼

一份**業內評審用的單頁報告**：讀者拿它拍板砍不砍、排產備不備。頁寬 1600，全部平鋪可 Cmd+F，沒有側欄、沒有摺疊。視覺語言與 novel-characters 同一套：冷灰印張 + 鐵鏽紅印記。

## 區塊順序（先交付後存檔）

```
頁首        書名 · 參數行 · 品質門徽章（13/13）· 匯出 JSON
KPI 帶      六張統計卡：總集數 / 爽點 / 角色分檔 / 主場景 / 生成難點 / 改編幅度
（病灶橫幅） 品質門有未過項時才出現，列出每一條
01 爽點節奏  圖/表 tab：預設時間軸，切到明細表看鋪墊與兌現
02 分集概覽  三列卡片（430px 起自適應），預設只顯示前三集：
             底部漸隱 + 「▾ 展開全部 N 集」，點一下全展開不再收起；≤3 集不收
03 場景概覽  整行，卡片多列網格（380px 起自適應）
04 關鍵決策  拍板過的三件事：砍了哪條線 / 合了哪些人 / 大爆點落在第幾集
05 每集排程矩陣  整行——60 集 × 25 角色的矩陣天然吃滿寬
06 資產量折算
07 人物表
08 改編說明  一句話核心 + 保留/砍掉/合併/風險四張表（evidence 用「」引文樣式）
09 品質門    完整 ✓/✗ 清單
```

改編說明放最後是有意的：它是「為什麼這麼改」的存檔，不是每次都要讀的交付。

**螢幕上收，紙上全展開**：tab 只是螢幕上的收納，`@media print` 裡兩個面板都輸出、分集全部展開、tab 條和展開按鈕隱藏。改摺疊相關樣式時 print 段要一起改，自測有斷言盯著。

## 圖表口徑（按 dataviz 方法定的）

全部單色系，**配色跑過驗證器**：大爆點 `#8a3324`、常規爽點 `#c56a4e`，在面板底色上六項檢查全過。全部內聯 SVG/CSS，**不引任何庫**。

### 關鍵決策（04）

三欄卡。砍線/合人清單來自 `adaptation.cut/merge`；**角色位統計、主角組名單、大爆點列表是算出來的**。可選的 `adaptation.cutNote / mergeNote` 是模型寫的結論句（"這意味著……"），鐵鏽紅底。大爆點列表首末帶「首個／終局」標記。

### 爽點節奏（01，圖/表 tab）

劇情時間軸：一條地平線，爽點是軸上的節點（大爆點 r9 實心、常規 r6，帶 2px 面板色描邊圈），節點上標型別 + 鋪墊摘句，**標籤上下交替防撞**，同一集多個爽點時翻到對面。**空檔直接標在軸上**（「— n 集空檔 —」），超過 `maxBeatGap` 的空檔變鐵鏽紅——違規在圖上自己喊。超過 20 集按每行 20 集折行。

⚠ **集刻度必須最後繪製**——它帶面板色底襯（`paint-order:stroke`），壓在節點豎線上仍可讀；先畫的話會被豎線蓋住。

### 每集排程矩陣（05）

角色 + 場景同一張網格，**一列豎著讀就是那一集的需求單**（要誰出場、在哪拍）。角色格深鏽紅、場景格淺鏽色，分帶行「場　景」隔開。一次性場景在合計列帶 ⚠，複用方案落腳註。格寬隨集數收（≤20 集 26px / ≤40 集 20px / ≤60 集 16px / 更多 12px），超寬橫向滾動。

⚠ **矩陣和場景概覽必須各佔整行，不要並排。** 並排在小樣例上好看，真實量級（60 集 × 25 角色 + 12 場景）下矩陣吃掉全部寬度、場景卡被擠成一條縫。另外 grid 裡放內容超寬的滾動容器時列寬要用 `minmax(0,1fr)`——grid item 預設 `min-width:auto`，會被內容撐爆。

### 場景概覽（03）

每場景一張卡：右上**淺灰劇集編號**（連續合寫 `1–6`、離散 `1 · 6`、太散只報數量，見 `fmtEps`）、出現集微條、**承載爽點**（算出來的：爽點落點 × 場景出現集）、主場景列出場角色 / 一次性場景列複用方案（鐵鏽紅）。**不用佔比環**——比例不驅動決策，落在哪幾集才驅動。

### 資產量折算（06）

純表格。角色三檔 + 場景環境 + 生成難點，全部由 `computeAssets` 折算，模型一個字不寫。

## 品質門

頁首徽章常駐（透過綠、未過紅）；有未過項時 KPI 帶下方彈**病灶橫幅**逐條列出；文末 09 是完整清單。✓/✗ 由 `gateReport()` 渲染時算好烘進頁面，**不是模型自評**。未過不阻止渲染——體檢模式要的就是把病灶擺出來。

## 介面文案

全部收在 `T` 表裡，**別把字串散進模板**。中文文案不用單字詞（保留/砍掉/合併，不寫保/砍/合）。v1 只有中文；要加語言時把 `T` 換成按 lang 取值的表。

## 匯出 JSON

頁首按鈕，下載的**就是 outline.json 原樣**——內嵌在 `<script type="application/json" id="outline-data">`。兩個坑：JSON 裡的 `<` 要轉成 `<`（防 `</script` 截斷）；`revokeObjectURL` 要延後調（防 Safari 搶跑存出空檔案）。

## 品質底線

- 不引任何外部資源，離線雙擊能開，自測正反兩面盯著
- 大綱資料是模型生成的，一律 `esc()` 轉義後拼進 HTML
- `@media print`：隱藏匯出按鈕、卡片不跨頁斷
- `prefers-reduced-motion` 關動效

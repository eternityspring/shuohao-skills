# 分卷摘要 · 中間產物

給你一卷原文（若干章），產出這一卷的改編原料。**只輸出 JSON，不要任何解釋、不要 markdown 圍欄。**

後面做大綱的人**看不到原文，只看得到你寫的摘要**——所以線索必須落在紙面上，不能指望"到時候再翻書"。

## 輸出格式

```json
{
  "plotlines": [
    { "name": "沈知微翻案線", "events": "這一卷裡該線發生了什麼，按順序，寫具體", "hookPotential": "這條線裡能當爽點用的時刻" }
  ],
  "characters": [
    { "name": "老周", "aliases": ["老伯"], "doing": "這一卷裡他做了什麼、和誰產生了關係" }
  ],
  "beatMaterial": [
    { "moment": "陸行遠當眾掏出口袋", "type": "身份揭破", "evidence": "口袋裡是一方舊硯，不是槍" }
  ],
  "settings": ["渡船船艙", "縣城當鋪"]
}
```

## 規則

- `plotlines` 按線整理不按章——章是物理切分，線才是改編單位
- `beatMaterial.evidence` **逐字複製原文片段，保持原文語言**。爽點素材必須能指回原文，這是「禁止憑書名腦補」的落地
- `characters.aliases` 把這一卷裡出現的所有稱謂都收進來，跨卷歸併靠它
- `settings` 只列實際發生過戲的地點，提到但沒進行動作的不算
- 不做取捨判斷——砍線合人是下一步的事，這一步只負責讓原料齊全

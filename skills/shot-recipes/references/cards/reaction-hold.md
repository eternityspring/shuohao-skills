## 意图

一句重话落地之后，不要急着接下一句，先切听者的脸。戏是在这两秒里成立的：说的人已经说完，观众要看见这话砸在谁身上。

这是**全库性价比最高的一张卡**，三重便宜叠在一起：不用写台词（省一次编剧），天然规避口型合成（AI 视频最容易穿帮的地方直接绕开），还给观众留出消化时间（节奏立刻像成片）。一段对话里每隔几句插一格反应，戏就有了呼吸。

代价只有一条：这一格什么都不能发生。它的全部难度在于**忍住不加东西**。

## 提示词骨架

固定一格，绝不延长成两格。

```
close-up, listener in frame（听者是谁、此刻的姿态与视线落点）,
与上一格同一盏主光、同一光比, no dialogue in this cut,
the mouth closed throughout（嘴全程闭着，不给任何口型）,
只给一个极小的具体动作（睫毛垂下 / 喉结动一下 / 手指收紧，三选一）, 机位固定不动
```

- **必须写「嘴是闭着的」**：`the mouth closed throughout`。不写这句，模型会自作主张给听者配上口型，反应格立刻变成接话格
- **只给一个极小的具体动作**，三选一：睫毛垂下 / 喉结动一下 / 手指收紧。写具体的那一个，不要写「露出震惊的表情」——抽象情绪词会被画成夸张的表情包
- **`<d>` 块留空**。台词、画外音、旁白，这一格一样都不挂。写了就破功
- 运镜固定 `Static Shot`。这张卡是全库唯一没有第二运镜选项的卡

## 参数表

| 旋钮 | 默认 | 区间 | 调节手感 |
| --- | --- | --- | --- |
| 单格秒数 | 2 秒 | 2–3 秒 | 全库最短的一格。超过 3 秒观众开始等下一句，「反应」就滑成「发呆」 |
| 景别 | close | close–medium | 情绪重收到 close；那个小动作在手上（收紧、松开）就退到 medium |
| 动作幅度 | 极小 | 极小–小 | 极小才像真的在听；一旦到「明显」，就变成表演给镜头看 |
| 动作数量 | 1 个 | 1 个 | 这个旋钮没有区间：皱眉、后退、摇头三样一起上就是默剧 |
| 台词 | 无 | 无 | 同样没有区间。要接话就另开一格，不要挤进这一格 |
| 运镜 | Static Shot | Static Shot | 推近会把「听见了」抬成「情绪高潮」，那是另一张卡的活 |

## 参考图约束

- **一张角色设定图（听者）必挂**——整格就是这张脸，任何漂移都在正中间
- **把上一格挂成这一格的参考图**：同一场戏同一盏光，光比一变观众就读成另一场戏。这条比角色图还要容易漏
- 提示词只写此刻的姿态与那一个小动作，长相与服装交给参考图
- **不要挂说话人的设定图**。这一格里不该有他，挂了模型就想把他塞进画面

## 已知坑

| 病 | 症状 | 治法 |
| --- | --- | --- |
| 呆立 | 面无表情站着 2 秒，等于空耗一格 | 给一个极小的具体动作：睫毛垂下 / 喉结动一下 / 手指收紧 |
| 开口 | 听者嘴动了，看着像在接话，还要对口型 | `no dialogue in this cut` 之外再显式写 `the mouth closed throughout` |
| 过量 | 皱眉、后退、摇头一起来，两秒演成默剧 | 一格只留一个动作，其余全部删掉 |
| 跳光 | 与上一格光比不同，接起来像另一场戏 | 上一格当参考图挂上，并且把光位与光比写进提示词 |
| 推近 | 给了 Push In，安静的反应被抬成高潮 | 这张卡固定 Static Shot；真要强调，另开一格处理 |

## 示例

《回信》R13：镜头留在父亲听着的那张脸上——3 秒，close，机位固定不动。

这一格是本卡的字面执行：`listener in frame` 是画面里唯一的人，`no dialogue in this cut` 加上「嘴全程闭着」，模型没有机会自作主张配一副口型。**全格只有一个极小的动作**——眼睛垂下去看那封信，再抬回来。不是「露出震惊的表情」，是一次具体的、写得进提示词的眼球运动。

它紧跟在正反打后面：R11 父亲开口，R12 儿子不接话，R13 把镜头交回父亲，让他听那段沉默。主光还是上一格那只裸灯泡，光比也没有变，三格接起来才是同一场戏——这也正是本卡与 `ots-shot-reverse` 最省的搭法：正反打给信息，反应静持给节奏。

## 意图

观众进入一个新空间，需要在三格之内拿到三样东西：**谁来了、这是哪儿、这地方有什么值得看**。三格各管一样——运动主体、大远景定场、关键局部——三格之后，这个空间就算立住了。

**这是一张三格配方**，不是三张卡的连写。少任何一格都缺信息：只有定场是明信片，只有主体是不知道身在何处，只有局部是没头没脑的特写。三格的顺序也不能换：第一秒必须有人在动。

## 提示词骨架

三格一组，三格都必须带 `consistent location anchors`。锚点先定下来（同一盏灯、同一段栏杆、同一种地面材质），再逐字复制进三格。

**第 1 格 · 运动主体**（`Tracking Shot`，medium 或 wide）：

```
medium shot, 主体在运动中（奔跑 / 推门 / 从画外走进来）, camera moves alongside
the subject, consistent location anchors:（锚点逐项点名——雾、木栈桥、马灯）, 光照状态
```

**第 2 格 · 大远景定场**（`Static Shot`，extreme wide 或 wide）：

```
extreme wide shot, 整个空间的全貌, 主体在画面里只占很小一块但是仍然可辨,
consistent location anchors:（与第 1 格逐字相同的那批锚点）, 天光与时间, 机位固定
```

**第 3 格 · 关键局部**（`Push In`，close 或 medium）：

```
close-up, 这个空间里最有信息量的一处局部（招牌 / 水面 / 器物 / 一双手）,
consistent location anchors:（锚点里的一项，在这一格看得最清楚）, 浅景深, 缓慢推近
```

- **必备短语只有 `consistent location anchors` 一条，因为它是三格都为真的不变量**：三格必须共享同一批空间锚点，缺了这批锚点，三格就是三个地方
- **「运动主体」只在第 1 格为真，所以留在正文里而不进必备短语。判据就是这一条——必备短语必须是这张配方每一格都成立的要求；只在某一格为真的要求写进正文，不设门。**设了门，另外两格必然假失败，配方从此没有人挂
- **锚点要逐字相同**：第 1 格写 `a rusted iron railing`，第 2、3 格就不许改写成 `an old metal fence`——同义替换在模型眼里就是另一样东西
- 台词一般不进这三格；要有，也只给第 3 格之后的那一格，让三件套保持纯粹的空间交代

## 参数表

| 旋钮 | 默认 | 区间 | 调节手感 |
| --- | --- | --- | --- |
| 每格秒数 | 2 / 4 / 3 秒 | 各 2–4 秒 | 定场那格信息量最大，最需要时间；三格总长压在 10 秒以内，超过就不像开场了 |
| 格数 | 3 格 | 3 格 | 这是配方的定义，不是旋钮；只给两格就退化成一次普通进场 |
| 三格顺序 | 主体 → 定场 → 局部 | 固定 | 把定场提到第 1 格就成了明信片开场，第一秒画面里没有人 |
| 锚点数量 | 3 项 | 2–4 项 | 太少锁不住空间；太多的话三格提示词都被锚点占满，主体反而被淹没 |
| 第 1 格运动量 | 中 | 中–大 | 走进画面是下限，奔跑与推门是上限；主体静止就是死画面 |
| 第 2 格主体占比 | 画高十分之一 | 二十分之一–六分之一 | 太小观众找不到人，太大就不成其为定场 |
| 第 3 格景别 | close | close–medium | 越近越像点题的特写；给到 medium 就变成第二个定场，三格白铺 |

## 参考图约束

- **一张场景设定图三格共用**——这是三格能被认成同一个地方的唯一保障，比锚点短语更硬
- 主体是人就挂角色设定图，**三格都要挂**：第 2 格里人很小也要挂，不挂那个小人会穿上别的衣服
- **链式挂参考图**：第 1 格出来之后挂给第 2 格，第 2 格出来之后挂给第 3 格。光线、天色、雾的浓度靠这条链锁死，不然三格三个样
- 提示词只写取景与此刻发生的事，空间长什么样交给场景设定图

## 已知坑

| 病 | 症状 | 治法 |
| --- | --- | --- |
| 静物开场 | 第 1 格写成招牌特写、空镜或者静止的物件，观众第一秒就划走 | 第 1 格必须有运动着的人；点题的静物挪到第 3 格去 |
| 三个地方 | 三格看着像三个不相干的场所，接不到一起 | `consistent location anchors` 与锚点原文逐字写进三格（门查这一条） |
| 定场提前 | 顺序改成定场 → 主体 → 局部，开场变成一张明信片 | 恢复顺序：先有人在动，再交代这是哪儿 |
| 空镜定场 | 第 2 格里根本没有主体，接不回第 1 格 | 定场格里必须留下主体，哪怕只占画高十分之一 |
| 天色三样 | 三格的天光对不上，一格黄昏一格正午 | 时间与天光三格共用同一句写死，并且链式挂参考图 |
| 锚点改写 | 三格的锚点换了说法，模型认成不同的物件 | 锚点短语逐字复制，不做任何同义替换 |

## 示例

《回信》里没有一组连续三格专门挂这张配方。最接近的是开头【到达】那一段：R01 航拍一片旧居民楼，只有四层一扇窗是暖的（extreme wide，`Truck Right`）→ R02 大远景院子，儿子只是画面里一个小点（extreme wide，静止机位）→ R03 跟着背影走进楼道（medium，`Tracking Shot`）。

它和标准三件套差在两处，都不是小差别：

- **顺序反了。** 三件套要求第一秒就有人在动，样片却把两格定场放在前面，运动主体压到第三格——它先要说清「这是哪座楼」，再说「这是谁」。换成本卡的排法，R03 得提到最前面：背影先走起来，院子随后打开。
- **缺第三件，也就是关键局部。** R03 之后直接进了屋，没有一格摘出这个空间里最有信息量的那一处。真按本卡写，第三格应当是一次缓慢的 `Push In` 近景，落在前两格里已经出现过的东西上——院子里那棵光秃秃的树，或者四层那扇亮着的窗。它得是局部，不能是新信息。

`consistent location anchors` 在 R01 与 R02 之间是成立的：同一批楼体、同一个院子、同一排晾衣绳与自行车棚，两格逐字复制。到 R03 就断了——进楼道等于把整套锚点换成墙裙与铁栏杆，而这恰恰是三件套不许发生的事情。

# 示例帧 · 出图与收编

示例帧是**卡片的证据**，不是插图。一张卡声明了 `example_frames`，等于宣称「这个配方我真的拍出来过，长这样」。举不出来就写空数组——`lint` 只拦「声明了却不存在」，不拦「没有」。**不装有**。

## ⚠️ 美术基线：所有示例帧都出自同一部片子

示例帧不是各出各的。**全部出自本 skill 自己的语汇样片《回信》**（`examples/vocab-reel.json`）——一个故事、两个人物、三个空间、三件道具。新出的帧必须落在这套基线里，否则整面卡片墙就散了。

| | 定死的内容 |
| --- | --- |
| **时代地点** | 1995 年，北方小城 |
| **人物（只有两个）** | 儿子 32：短发，深蓝工装夹克，灰绿衬衫扎进裤子 · 父亲 60：花白短发，深灰开衫，衬衫 |
| **空间（只有三个）** | 屋里（圆桌）· 楼道 · 楼外（院子与楼体） |
| **道具（只有三件）** | 牛皮纸信 · 红搪瓷暖水瓶（金属盖、侧提手）· 白色红边搪瓷缸 |
| **屋里陈设** | 齐胸浅绿墙裙、上半墙开裂白灰、水磨石地、圆木桌、桌上方一只裸白炽灯泡、木叶吊扇、墙上挂历、后墙蓝玻璃窗 |
| **光** | 裸灯泡是暖主光，蓝玻璃窗给冷补光，**暗部始终保留细节** |
| **色彩** | 水泥灰 + 墙裙绿打底，暖水瓶与搪瓷缸的红是唯一暖色点缀 |
| **质感** | 轻微胶片颗粒、柔和高光、16:9 |

**这条纪律最重要：年代感交给器物，不交给调色。** 墙裙、水磨石、圆桌、暖水瓶、吊扇负责说 1995；**绝不许**加发黄滤镜、褪色、暗角、漏光、VHS 扫描线。一上滤镜，「暗部保留细节」「高调 / 低调」「光比差几档」这些卡就没法演示了——观众只会看见滤镜。

其余两条硬约束：**不许出现第三个人**（楼道邻居、院子行人一律不要）；**不许有任何 logo、品牌、可读文字**（招牌、报纸、信纸上的字都不许可读）。

产品那一组**不搭影棚白底**，就拍桌上的暖水瓶与搪瓷缸，背景沉进暗处让轮廓读得干净——90 年代的搪瓷器天然无品牌，正好符合产品卡「不许有 logo」的纪律。

## 两个来源，优先第一个

| 来源 | 什么时候用 | 代价 |
| --- | --- | --- |
| **复用样片里已经出过的帧** | 《回信》里这一格恰好就是这张卡 | 零额度，而且天然满足「真的做过」 |
| **照样片新出一格** | 样片里有这一格但还没出图 | 每帧一次 codex 调用 |

**不要去别的 skill 的样例里借帧。** 这个 skill 是自包含、可以整个拷走的，借来的帧一旦离开原仓库就没了出处；而且别人的样例只能展示别人那一种题材。

## 收编一张真实分镜帧

1. 确认它真的演示了这张卡——**凡是静帧能证明的必备短语，画面里必须看得见**。`hands-tell` 的 `hands only` 与 `no face visible`，画面里就不能露脸；`handheld-follow-in` 的 `subject seen from behind`，画面里就得是背影。至于 `handheld feel`、`motion blur streaks` 这类描述运动的短语，静帧证明不了，**别假装它证明了**——卡片的 `## 示例` 一节要写清楚这张帧演示的是哪一条
2. 复制到 `references/cards/frames/`，命名 `<卡片 id>-<序号>.webp`（序号从 1 起）
3. 转 webp 压掉体积——**帧要进仓库，PNG 一张两三兆，十张就把仓库拖胖**。质量 82 起步，看不出退化就别再往上加
4. 卡片 frontmatter 写 `example_frames: [<卡片 id>-1.webp]`，`## 示例` 一节写明它出自哪一段哪一格
5. 跑 `lint`

多格配方（`cuts` 下限 ≥ 2）收编时**要么整组收要么不收**：`ots-shot-reverse` 只放一张过肩，读卡的人看不出前景肩换了边——而换边正是这张配方的全部内容。

## 专门出图

出图走 codex 内置的 `$imagegen`，**不需要 API key**，用本机 codex 登录态。**没有 codex 就整步跳过**，卡片显示「示例帧未生成」占位，其余产出照常。

### 调用契约

- **跑在 codex 里**：直接用 `$imagegen`，不要再 shell 出去调 `codex exec`
- **跑在 Claude Code**：shell 调本机 codex，**先探测版本最高的 binary**——机器上可能装了多个 codex，版本不够新的直接报错「requires a newer version of Codex」：

  ```bash
  find_codex() {
    local best="" best_n=0 c v n
    # command -v 放第一个：尊重用户的 PATH；后面几个是常见安装位置兜底
    for c in "$(command -v codex 2>/dev/null)" \
             "$HOME/.npm-global/bin/codex" \
             "$HOME/.local/bin/codex" \
             "$(npm prefix -g 2>/dev/null)/bin/codex" \
             /opt/homebrew/bin/codex \
             /usr/local/bin/codex; do
      [ -n "$c" ] && [ -x "$c" ] || continue
      v=$("$c" --version 2>/dev/null | grep -oE '[0-9]+\.[0-9]+\.[0-9]+' | head -1)
      [ -n "$v" ] || continue
      n=$(echo "$v" | awk -F. '{printf "%d%03d%03d", $1, $2, $3}')
      [ "$n" -gt "$best_n" ] && { best_n=$n; best=$c; }
    done
    [ -n "$best" ] && echo "$best"
  }
  CODEX=$(find_codex)
  ```

  `$CODEX` 为空就跳过出图。
- 所有调用套 `env -u NODE_OPTIONS`（codex 继承坏的 `NODE_OPTIONS` 会启动即崩）
- **一帧一次调用，绝不批量**（PNG 字节会撑爆 rollout）
- 用了 `-i/--image` 这类变长参数时 **prompt 必须走 stdin**
- 提示词里明写 `copy to ./<卡片 id>-<序号>.png`，别让图留在 codex 默认目录
- 提示词末尾固定加：`No text, no watermark, no borders — a single clean full-bleed frame.`
- 单张失败跳过不阻断，最后汇总说明
- **不碰 CLI fallback**（要 `OPENAI_API_KEY`）

### 提示词怎么写

**照这张卡自己的「提示词骨架」写，再落进上面那套美术基线**——示例帧的作用就是把骨架兑现一次，骨架里的必备短语一条不许少。三条纪律：

1. **人物、空间、道具只能从基线那三张表里取**，不许新开。卡片是给所有人用的语汇，但示例帧是一部片子的剧照集——**统一压倒多样**。读卡的人不会因为九张图都在同一间屋里就以为这张卡只能用在这间屋里，却一定会因为九张图九个世界而觉得这个库很散
2. **画面里只留这张卡要证明的东西**。多一个人、多一件道具、多一道装饰光，读卡的人就分不清哪一部分是语汇、哪一部分是布景
3. **每一格都挂参考图，按身份链依次往下**。建立镜头（两人同框全景）是链条的根，正打挂它、反打挂正打、面部特写挂反打；手部与产品直接挂建立镜头。**一格不挂，那一格的人和屋子就会自己漂**

### 多帧卡的一致性

一张卡两帧以上时，**第二帧必须挂第一帧当参考图**，提示词明写 `the SAME two people, same clothes, same room as this reference`——同一张卡里换了人，这张卡就从「演示配方」变成「演示 AI 会换人」。

`ots-shot-reverse` 的两帧另有一条硬要求：**前景肩必须换边**（第 1 帧前景在左，第 2 帧就在右），并且两帧的空间关系要对得上——两个人的左右位置不许互换。

## 拿到图先扫一眼

- **必备短语兑现了没有**——这是第一条，不过就重生成，别凑合
- 景别对不对（提示词写 `close-up` 出来却是全景 → 重生成）
- 有没有多出来的人或者道具（背景围观群众是最常见污染）
- 多帧卡：两帧是不是同一个人、同一个空间、同一套光

## 收尾

```bash
# 转 webp（用仓库惯用的压图 skill 或者 cwebp）
cwebp -q 82 <卡片 id>-1.png -o references/cards/frames/<卡片 id>-1.webp

env -u NODE_OPTIONS node scripts/shot-recipes.mjs lint
env -u NODE_OPTIONS node scripts/shot-recipes.mjs render --html > references/cards/gallery.html
```

**报告要写进 `references/cards/`**——图是相对路径 `frames/…`，写到别处图就不显示了。

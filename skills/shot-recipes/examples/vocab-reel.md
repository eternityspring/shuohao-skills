# 语汇样片《回信》· 运镜脚本

**1995 年，北方小城。36 格，2 分 17 秒。**

这是 `shot-recipes` 自己的展示数据，`vocab-reel.json` 的可读版本。它存在的理由只有一个：**把这个库的镜头语汇用一个故事串起来**。

所以它的写法和普通短片脚本反过来——普通脚本是先有戏、再想怎么拍；这一份是**先定下要演示哪 34 张卡，再写一个能把它们串成一部片子的故事**。能串起来，说明这些语汇本来就属于同一套系统；串不起来，说明这个库是散的。

**人物 2 个 · 空间 3 个 · 道具 3 件。** 元素少到这个程度是故意的：元素越少，跨 36 格的一致性越容易守，出图时越不容易崩，读的人越记得住。

---

## 故事

儿子收到一封信，回到十七年没进过的老房子。

父亲坐在圆桌那头。桌上摆着那封信，父亲一直按着，不给。

**反转在折痕上。** 那封信是儿子自己写的——十七年前他离家那天留在桌上的，只有三个字：别找我。父亲把它折了又折，读了十七年，最后寄了回去。信封上是儿子自己的字迹，所以他才回来。

儿子走的时候，信留在桌上。**这一次它是父亲的了**——把「别找我」留下，等于把那句话收回来。

楼下拉远，四层那扇窗还亮着。

## 这 36 格演示了哪些卡

34 张（`ots-shot-reverse` 与 `whip-blur-bridge` 各占两格）。四个题材各有落点：

| 题材 | 段 | 说明 |
| --- | --- | --- |
| **drama 剧情** | 到达 / 对坐 / 那封信 / 离开 | 对话、情绪、揭示、进场、反应、转场、强调七个配方类目全在这里 |
| **product 产品展示** | 器物 | 不搭白底，用故事里的器物拍 |
| **talking-head 口播** | 他说 | 理解成对镜讲述，同时是叙事结构的一部分 |
| **vlog** | 到达 | 第一人称走进一个空间，手持与稳定器各一格 |

**样片覆盖不了全部 71 张卡，这是故意的，也是诚实的。** 画廊报告加上 `--check` 之后会列出「从没被使用的卡」——36 格演示不了 71 张，不装繁荣。

## 怎么用这份样片

```bash
# 机器复核：每一格的提示词里，那张卡的必备短语有没有真的写进去
node scripts/shot-recipes.mjs check examples/vocab-reel.json
# → 36 处配方引用 · 0 处违规

# 喂进画廊报告，多出一块「覆盖对照」
node scripts/shot-recipes.mjs render --html --check examples/vocab-reel.json > references/cards/gallery.html
```

`vocab-reel.json` 是机器读的那一份，每一格带完整的英文分镜图提示词；这份 `.md` 是给人读的。**两边的格号是同一套契约**，改了一边要改另一边。

示例帧全部出自这 36 格，出图纪律见 `references/frame.md`。

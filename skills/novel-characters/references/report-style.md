# report.html 的設計約定

報告由 `scripts/novel-characters.mjs render --html` 產生，樣式全部內聯在 `renderHtml()` 裡。**改樣式只改那一處**，不要另起模板。

這份文件記錄為什麼長這樣，免得後來的改動把它改回一個通用的卡片牆。

## 它是什麼

不是行銷頁，是**製作用的角色設定集**。讀者是要拿這些提示詞去真生圖、真配音的人。頁面唯一的工作：**讓人快速抓到對的提示詞，同時相信人物側寫有原文依據。**

所有設計決定都從這一句推出來。

## 多語言

介面文案在 `novel-characters.mjs` 的 `STRINGS` 表裡，`zh-TW` / `zh` / `en` / `ja` 四套。加語言就加一個鍵，**別把中文硬編碼進模板**——`renderEntry` / `renderHtml` 拿到的 `t` 就是那張表。

未知語言碼退回 `en` 的介面骨架（`strings()` 裡做的），但 `<html lang>` 仍寫實際語言碼。理由：角色內容確實是那個語言，介面詞沒翻譯總比整篇混亂強。

**字體跟著語言走**：`zh-TW`（以及 `zh-HK` / `zh-Hant`）挑 TC 字體，其餘挑 SC 字體。
判斷在 `isTraditionalChinese()`。Songti SC 那一串在台灣機器上多半沒裝，掉回系統預設會跟正體字形不搭。

## 四條不能破的規矩

### 1. 雙字域

中文印刷體本身就分工，直接用：

| 字體 | 語域 | 用在 |
| --- | --- | --- |
| **宋體** `--serif` | 敘事——關於故事的 | 書名、角色名、一句話、**故事摘要**、**原文引文** |
| **黑體** `--sans` | 分析——關於角色的 | 側寫正文、欄位標籤、介面 |
| **等寬** `--mono` | 機器輸入 | 英文提示詞、序號 |

真正逐字來自原文的只有 `.source blockquote`，它額外帶鐵鏽紅邊欄和「」引號——**那對引號是「這是原文」的唯一標記**，別拿去裝飾摘要或一句話。

這是這份報告跟任何一個角色卡產生器的區別所在，別把它統一成一種字體。

全部用系統字體，**不許引外部字體**——報告要能離線點兩下打開。

### 2. 不藏內容

**沒有頁籤、沒有摺疊、沒有「展開更多」。** 整頁可以 Cmd+F 搜到任何一個字。

第一版用了三個頁籤，看著乾淨，但它讓人沒法搜尋、沒法列印、沒法一眼掃完一個角色。工作文件不該藏東西。

### 3. 推斷標記要高亮

`（推斷）` 和 `(inferred)` 由 `marked()` 自動包成 `<span class="inf">`，帶淺鐵鏽紅底。

這是本報告的簽名細節。這個工具的核心承諾就是「哪些有原文依據、哪些是為了能用而補的」，把它做成視覺，比寫在文件裡有用。頁尾也有一句說明。

## 配色

冷灰印張 + 鐵鏽紅印記。**紅色只用在跟原文有關的地方**：引文的邊欄和引號、主角標籤、hover 態。別拿它當通用強調色。

| token | 淺色 | 用途 |
| --- | --- | --- |
| `--paper` | `#e9eae5` | 冷灰印張，不是暖奶油 |
| `--panel` | `#e1e3dd` | 提示詞區塊 |
| `--ink` | `#191d21` | 藍黑，不是純黑 |
| `--seal` | `#8a3324` | 鐵鏽紅，只給原文 |

深色模式由 `prefers-color-scheme` 切換，**設定圖的印張永遠白底**——它是一張紙，不是 UI 面板。

## 尺寸與格線 ⚠️ 硬性

- **頁面上限 1800px**（`.wrap{max-width:1800px}`）
- **一排最多三個角色**

「最多三個」不是寫死欄數，是靠 `minmax` 卡出來的：

```css
.cast{grid-template-columns:repeat(auto-fit,minmax(460px,1fr));gap:28px}
```

1800 減去兩側 40 內距剩 1720：三欄 `3×460+2×28=1436` 裝得下，四欄 `4×460+3×28=1924` 裝不下。**這三個數（1800 / 460 / 28）是連動的，改一個要重算另外兩個**，自測裡有斷言盯著。窄螢幕自然降到兩欄、一欄。

```

《書名》· 角色                                 ← 宋體大標題
4 位角色 · 3 張設定圖 · 依戲份排序
════════════════════════════════════════════
┌── 故事摘要 ─────────┐  01 沈知微 ······ 主角   ← 摘要與目錄並排，
│ 民國年間的清晨…      │  02 陸行遠 ······ 主要     把 1800 的寬度用起來
└────────────────────┘  03 老周  ······· 主要
                        04 胡二爺 ······ 配角   ← 序號是排名不是裝飾：
                                                  依出現塊數排的戲份權重

┌─ 01 沈知微 主角 ──┐ ┌─ 02 陸行遠 ──┐ ┌─ 03 老周 ──┐
│ 一句話            │ │              │ │            │
│ [設定圖]          │ │ [設定圖]     │ │ [設定圖]   │
│ 人物側寫          │ │ …            │ │ …          │
│  外貌 / ▍原文依據 │ │              │ │            │
│ 造型              │ │              │ │            │
│  [提示詞] 複製    │ │              │ │            │
│ 聲音              │ │              │ │            │
```

卡內三組（人物側寫 / 造型 / 聲音）**豎排**，`.groups{display:block}`。卡片只有 555px 寬，再分欄就擠沒了。

## 每段提示詞一個複製按鈕

不能少。目前每個角色 8 個：風格標籤、生圖 EN、生圖中文、負向、設定圖 EN、音色 EN、音色中文、整份 JSON。自測裡有斷言盯著這個數。

## 品質底線

- 響應式到手機（三欄 `auto-fit` 塌成一欄）
- 鍵盤焦點可見（`.copy:focus-visible`）
- `prefers-reduced-motion` 關掉全部動效和平滑捲動
- `@media print` 隱藏按鈕和目錄、條目不跨頁斷
- 角色資料是模型產生的，**一律 `esc()` 跳脫**後再拼進 HTML

## 動效

只有一處：目錄逐行漸顯（45ms 階梯）。其餘靠排版和留白，不靠動畫。

# report.html 的設計約定

報告由 `scripts/novel-characters.mjs render --html` 生成，樣式全部內聯在 `renderHtml()` 裡。**改樣式只改那一處**，不要另起模板。

這份檔案記錄為什麼長這樣，免得後來的改動把它改回一個通用的卡片牆。

## 它是什麼

不是行銷頁，是**製作用的角色設定集**。讀者是要拿這些提示詞去實際生圖、實際配音的人。頁面唯一的工作：**讓人快速抓到對的提示詞，同時相信人物側寫有原文依據。**

所有設計決定都從這一句推出來。

## 多語言

介面文案在 `novel-characters.mjs` 的 `STRINGS` 表裡，內建 `zh-TW` / `zh` / `en` / `ja` 四套。加語言就加一個鍵，**別把中文硬編碼進模板**——`renderCharacter` / `renderGraph` / `renderHtml` 拿到的 `t` 就是那張表。

內建表沒有的語言，由 skill 現場翻一份塞進 `cast.json` 的 `ui`，`strings()` 合並進來。所以支援的語言不受內建表限制。函式模板（`docTitle` / `counts` / `graphCounts` 這些）**不接受 `ui` 覆蓋**，未知語言碼會退回 `en` 的骨架，但 `<html lang>` 仍寫實際語言碼。

## 骨架

```
┌─ 頂欄 60px ─────────────────────────────────────────────┐
│ 書名        [搜尋]                     角色設定集 · 計數   │
├──────────────┬──────────────────────────────────────────┤
│ 左欄 400px    │ 主區 max-width 1500px                     │
│ 故事摘要（三行）│                                          │
│ ▸ 關係圖譜     │  ← 圖譜和角色詳情互斥，一次只顯示一個       │
│ 角色 01 …     │                                          │
│ 角色 02 …     │  01 角色名  主角        一句話              │
│ 角色 03 …     │  ┌──────────────┬──────────┐             │
│              │  │ 設定圖 + 側寫   │ 資訊卡     │  1fr / 500px │
│              │  ├──────────────┴──────────┤             │
│              │  │ 原文依據                  │             │
│              │  ├──────────────┬──────────┤             │
│              │  │ 生圖提示詞     │ 音色提示詞 │  1fr / 1fr   │
└──────────────┴──────────────────────────────────────────┘
```

左欄 `position:sticky` 滿高滾動；主區一次只 `display:block` 一個 `.char`。

**斷點**：`.shell` 1080 塌單欄、`.upper` 1240 塌單欄、`.prompts` 900 塌單欄、`.graph-body` 1100 塌單欄。

## 四條不能破的規矩

### 1. 雙字域

中文印刷體本身就分工，直接用：

| 字型 | 語域 | 用在 |
| --- | --- | --- |
| **宋體** `--serif` | 敘事——關於故事的 | 書名、角色名、一句話、**故事摘要**、**原文引文**、圖譜的節點名 |
| **黑體** `--sans` | 分析——關於角色的 | 側寫正文、欄位標籤、介面、圖譜的關係文字 |
| **等寬** `--mono` | 機器輸入 | 英文提示詞、序號 |

真正逐字來自原文的只有 `.source blockquote`，它額外帶鐵鏽紅邊欄——**那條邊欄是「這是原文」的唯一標記**，別拿去裝飾摘要或一句話。

這是這份報告跟任何一個角色卡生成器的區別所在，別把它統一成一種字型。

全部用系統字型，**不許引外部字型**——報告要能離線雙擊開啟。

### 2. 螢幕上收，紙上全展開

螢幕上一次只看一個角色，提示詞摺疊在 `<details>` 裡，摘要只留三行。**但 `@media print` 裡全部強制展開**：所有角色、所有提示詞、關係圖譜都要打得出來。

這是有意的取捨：早期版本把四個角色平鋪成卡片牆，看著滿，實際一屏什麼都讀不完。收起來是為了讓當前這個角色能被讀完，不是為了藏東西——所以紙上必須是完整的一份。

改摺疊相關的樣式時，**print 那一段要一起改**，自測裡有斷言盯著。

### 3. 推斷標記要高亮

`（推斷）` 和 `(inferred)` 由 `marked()` 自動包成 `<span class="inf">`，帶淺鐵鏽紅底。半形/全形 × 中英四種寫法都要認。

這是本報告的簽名細節。這個工具的核心承諾就是「哪些有原文依據、哪些是為了能用而補的」，把它做成視覺，比寫在檔案裡有用。頁尾也有一句說明。

### 4. 自包含

**不許引任何外部資源**——沒有 CDN 程式、沒有外部字型、沒有遠端圖片。關係圖譜是手寫的內聯 SVG 而不是 d3，就是這條規矩逼出來的。自測裡有斷言正面反面都盯著（既檢查產物裡沒有 `<script src>`，也檢查那條正則本身抓得到東西，免得是個永遠為真的假測試）。

## 配色

冷灰印張 + 鐵鏽紅印記。**紅色只用在跟原文有關的地方和當前選中態**：引文邊欄、主角標籤、圖譜裡被點亮的弦。別拿它當通用強調色。

| token | 值 | 用途 |
| --- | --- | --- |
| `--paper` | `#eceded` | 冷灰印張，不是暖奶油 |
| `--panel` | `#f5f6f5` | 提示詞塊、資訊卡、圖譜畫布 |
| `--side` | `#e4e6e3` | 左欄 |
| `--ink` | `#191d21` | 藍黑，不是純黑 |
| `--seal` | `#8a3324` | 鐵鏽紅 |
| `--seal-soft` | `#8a332412` | 推斷標記的底、圖譜選中行的底 |

**沒有深色模式。** 設定圖是白底印張，報告是冷灰印張，兩者一起反色會讓設定圖看著像貼上去的。

## 關係圖譜

一個跟角色詳情互斥的全景檢視，`.main.gmode` 時顯示。

**佈局在 Node 裡算好寫進 SVG**，瀏覽器端只管加 `hot` / `dim` 兩個類。理由同上——不引庫。

- 圓環佈局，半徑跟人數走：`max(130, min(260, 40 + n*14))`，兩側留 110 給名字
- 弦是二次貝塞爾，控制點往圓心拉 0.35。直線在人多時會糊成一團網
- 節點大小按 `importance` 分檔，主角實心鐵鏽紅
- 每個節點帶一個 **r=24 的透明命中區**（`.ghit`）。可見圓點只有十來個畫素，不加這層壓不準

⚠️ **命中區和可見圓點必須各有各的類**（`.ghit` / `.gdot`）。都寫成 `circle` 的話，`.gnode.lead circle` 會把命中區一起染成一個大紅塊。

⚠️ **關係文字沿弦按序號錯位**（`t = 0.5 + ((i%3)-1)*0.14`），不要都放 t=0.5。正對面兩個角色之間，弦的中點正好是圓心，全放中點會摞成一坨。錯位挪的是文字，弦本身不動。

關係文字截到 **6 字**，全文進 `<title>`。畫布只有 480 單位寬，一條 12 字的標籤佔掉 27%，相鄰兩條直接疊上。邊 ≤ 14 條預設標出來，再多預設收起，頂部有開關；**收起狀態下懸停的那條仍然要顯示**。

## 匯出 JSON

頂欄那個按鈕下載的**就是 `cast.json` 本身的形狀**，不是另一套匯出格式。這條是契約：外部工具改完要能直接重新匯入 `render`，也要能過 `validate`，自測裡有斷言盯著。

資料以 `<script type="application/json" id="cast-data">` 內嵌一份，點匯出只是包成 Blob 下載，**不發送網路請求**。

⚠️ **JSON 裡的 `<` 必須轉成 `<`**。正文裡出現一個 `</script` 就能把資料塊提前截斷。`<` 在 JSON 裡只可能出現在字串值中，所以整體替換是安全的。

⚠️ **`URL.revokeObjectURL` 不能跟在 `a.click()` 後面立刻調**。Safari 會搶在下載讀完之前撤掉 blob，使用者存下來是個空檔案。延後回收。

## 每段提示詞一個複製按鈕

不能少。目前每個角色 7 個：生圖本地/EN、設定圖 EN、反向、音色本地/EN、整份 JSON。有設定圖的還多一個「複製圖片」——複製的是**圖片本身**不是路徑，非 PNG 先過一遍 canvas 轉碼（Safari 只認 `image/png`）。自測裡有斷言盯著這個數。

## 品質底線

- 響應式到手機（所有多欄都有斷點塌成一欄）
- 鍵盤焦點可見（`.copy` / `.rost` / `.gnode` / `.grow` 都有 `:focus-visible`）
- SVG 的 `<g>` 不是原生按鈕，回車/空格要自己接
- `prefers-reduced-motion` 關掉全部動效和平滑滾動
- `@media print` 隱藏頂欄和左欄、展開全部內容、條目不跨頁斷
- 角色資料是模型生成的，**一律 `esc()` 轉義**後再拼進 HTML；`marked()` 內部已經轉過，別再套一層

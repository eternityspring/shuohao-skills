# 畫風預設

生圖風格可選。**預設 `realistic`**，想要動畫質感就用 `ghibli`，想要真人選角感就用 `photoreal`。

預設定義在 `scripts/novel-characters.mjs` 的 `STYLE_PRESETS` 裡，跑
`node scripts/novel-characters.mjs styles` 可以把整段印出來直接用。

| id | 說明 |
| --- | --- |
| `realistic` | 半寫實厚塗。預設 |
| `ghibli` | 吉卜力式手繪賽璐璐動畫 |
| `photoreal` | 擬真實拍，劇組試裝定妝照的質感 |

## ⚠️ 換風格是整套換，不是只換一句「畫風」

每個預設自帶五塊，**必須整塊取用，不要混搭**：

| 塊 | 作用 |
| --- | --- |
| `render` | 渲染方式那句 |
| `surface` | 皮膚、眼睛、頭髮、布料怎麼處理 |
| `lighting` | 光照 |
| `negative` | 負向提示詞 |
| `tags` | 風格標籤 |

**三個預設的 `negative` 立場兩兩不同**，這是整件事最容易搞反的地方：

| 預設 | 禁 `photorealistic` / `3d render`？ | 禁 `illustration` / `painting` / `anime`？ |
| --- | --- | --- |
| `realistic` | **絕不能** | 不禁——它本來就是畫出來的 |
| `ghibli` | **必須** | 不禁 |
| `photoreal` | **絕不能** | **必須** |

- `realistic` 一邊要真實感一邊禁真實感是自相矛盾的，它禁的是「假」（塑膠皮膚、無毛孔娃娃臉、完全對稱的臉）
- `ghibli` 要禁，寫實的那些細節在這裡全是反效果
- `photoreal` 反過來：它要的是**照片**，所以禁的是「畫」。漏了這一條，模型很容易交一張插畫交差

`surface` 同理：

- `realistic` 要毛孔、皮下散射、根根分明的碎髮、布料織紋
- `ghibli` 明確要**無毛孔、無皮膚紋理、成簇的髮絲、平塗無織紋的布料**
- `photoreal` 走得更遠：真實毛孔和汗毛、不修圖、痣和雀斑留著、眼裡有實拍的高光、
  眉眼誠實地不對稱、布料有真實重量和車縫線

把寫實那段帶進吉卜力，出來就是個四不像。

`validate` 會檢查這幾條：風格與負向提示詞搞反了直接報錯。

## `photoreal` 和 `realistic` 差在哪

不是「更寫實一點」，是**根本不同的東西**：

- `realistic` 仍然是**畫出來的**——厚塗、筆觸、繪畫感
- `photoreal` 要的是**拍出來的**——真人、真相機、50–85mm 鏡頭、中性暖灰無縫背景、
  劇組服裝組試裝定妝照的成品感

所以 `photoreal` 的 `render` 第一句就把話講死：`Live-action photography, not illustration`。

## 光照的差別

- `realistic` / `photoreal` **分區打光**：左欄半身像給方向主光 + 環境遮蔽（要體積），
  右側三視圖和細節條平光正交（要去背和量比例）
- `ghibli` **全圖平光**：均勻日光 + 單層柔和陰影。平光本來就是這個風格的一部分，
  不需要分區

`photoreal` 的分區跟 `realistic` 同一套邏輯，只是把「柔和主光」換成實拍的柔光箱
和反光板補光。

## 版面不隨風格變

16:9 三區、34%/66% 比例、人物比例協調、細節讓位不是人物讓位——這些是**版面規則**，
三個風格都一樣。變的只有渲染質感。

## 加新預設

往 `STYLE_PRESETS` 裡加一個鍵，五塊寫全，`label` 給齊內建介面語言那幾套
（`zh-TW` / `zh` / `en` / `ja`）。自測會檢查完整性，也會檢查打光要麼分區、
要麼明確寫成全圖平光。

`validate` 判斷「該不該禁寫實」是拿**預設自己的 `negative`** 當基準的，
所以新增預設不用回頭改校驗邏輯——把立場寫進 `negative` 就行。

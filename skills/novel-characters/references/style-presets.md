# 画风预设

出图风格可选。**默认 `realistic`**，想要动画质感就用 `ghibli`，想要真人选角感就用 `photoreal`。

预设定义在 `scripts/novel-characters.mjs` 的 `STYLE_PRESETS` 里，跑
`node scripts/novel-characters.mjs styles` 可以把整段打出来直接用。

| id | 说明 |
| --- | --- |
| `realistic` | 半写实厚涂。默认 |
| `ghibli` | 吉卜力式手绘赛璐璐动画 |
| `photoreal` | 拟真实拍，剧组试装定妆照的质感 |

## ⚠️ 换风格是整套换，不是只换一句「画风」

每个预设自带五块，**必须整块取用，不要混搭**：

| 块 | 作用 |
| --- | --- |
| `render` | 渲染方式那句 |
| `surface` | 皮肤、眼睛、头发、布料怎么处理 |
| `lighting` | 光照 |
| `negative` | 反向提示词 |
| `tags` | 风格标签 |

**三个预设的 `negative` 立场两两不同**，这是整件事最容易搞反的地方：

| 预设 | 禁 `photorealistic` / `3d render`？ | 禁 `illustration` / `painting` / `anime`？ |
| --- | --- | --- |
| `realistic` | **绝不能** | 不禁——它本来就是画出来的 |
| `ghibli` | **必须** | 不禁 |
| `photoreal` | **绝不能** | **必须** |

- `realistic` 一边要真实感一边禁真实感是自相矛盾的，它禁的是「假」（塑料皮肤、无毛孔娃娃脸、完全对称的脸）
- `ghibli` 要禁，写实的那些细节在这里全是反效果
- `photoreal` 反过来：它要的是**照片**，所以禁的是「画」。漏了这一条，模型很容易交一张插画交差

`surface` 同理：

- `realistic` 要毛孔、皮下散射、根根分明的碎发、布料织纹
- `ghibli` 明确要**无毛孔、无皮肤纹理、成簇的发丝、平涂无织纹的布料**
- `photoreal` 走得更远：真实毛孔和汗毛、不修图、痣和雀斑留着、眼里有实拍的高光、
  眉眼诚实地不对称、布料有真实重量和车缝线

把写实那段带进吉卜力，出来就是个四不像。

`validate` 会检查这几条：风格与反向提示词搞反了直接报错。

## `photoreal` 和 `realistic` 差在哪

不是「更写实一点」，是**根本不同的东西**：

- `realistic` 仍然是**画出来的**——厚涂、笔触、绘画感
- `photoreal` 要的是**拍出来的**——真人、真相机、50–85mm 镜头、中性暖灰无缝背景、
  剧组服装组试装定妆照的成品感

所以 `photoreal` 的 `render` 第一句就把话讲死：`Live-action photography, not illustration`。

## 光照的差别

- `realistic` / `photoreal` **分区打光**：左栏半身像给方向主光 + 环境遮蔽（要体积），
  右侧三视图和细节条平光正交（要抠图和量比例）
- `ghibli` **全图平光**：均匀日光 + 单层柔和阴影。平光本来就是这个风格的一部分，
  不需要分区

`photoreal` 的分区跟 `realistic` 同一套逻辑，只是把「柔和主光」换成实拍的柔光箱
和反光板补光。

## 版面不随风格变

16:9 三区、34%/66% 比例、人物比例协调、细节让位不是人物让位——这些是**版面规则**，
三个风格都一样。变的只有渲染质感。

## 加新预设

往 `STYLE_PRESETS` 里加一个键，五块写全，`label` 给齐内置界面语言那几套
（`zh-TW` / `zh` / `en` / `ja`）。自测会检查完整性，也会检查打光要么分区、
要么明确写成全图平光。

`validate` 判断「该不该禁写实」是拿**预设自己的 `negative`** 当基准的，
所以新增预设不用回头改校验逻辑——把立场写进 `negative` 就行。
